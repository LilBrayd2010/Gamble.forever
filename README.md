# ⚔️ Gamble Forever — A DnD Tavern Gambling App

A fantasy-themed gambling app with Dungeons & Dragons aesthetics. Step into the Tavern of Eternal Fortune, create your character, collect daily gold, and risk it all across five unique tavern games.

## 🎮 Features

### Character System
- Choose from 4 classes: **Rogue**, **Wizard**, **Warrior**, **Bard**
- Each class has a unique passive perk that affects gameplay

### Daily Login Bonus
- **250 gold** every day
- Streak bonuses for consecutive logins (up to 500g + mystery loot at 7+ days)

### 5 Gambling Games
| Game | Description | Unlock |
|------|-------------|--------|
| 🎲 **Dragon's Dice** | Roll 2d6 against the house | Level 1 |
| 🃏 **Blackjack of the Abyss** | Classic 21 with DnD-themed cards | Level 1 |
| 🎡 **Fate's Wheel** | Spin for multipliers, jackpots, or ruin | Level 1 |
| ⚔️ **Monster Battle Bet** | Pick a champion for d20-based combat | Level 3 |
| 🗡️ **Dungeon Chests** | Treasure, break even, or mimic? | Level 5 |

### Progression
- **XP & Leveling** — earn XP from every game, unlock new content
- **Loot System** — cosmetic items with 5 rarity tiers (Common → Legendary)
- **Personal Stats** — track wins, losses, streaks, and more

### Class Perks
| Class | Perk |
|-------|------|
| 🗡️ Rogue | +10% chance to re-roll on Dragon's Dice |
| 🔮 Wizard | Fate's Wheel LOSE slot replaced with 2x |
| 🛡️ Warrior | +15% attack/defense in Monster Battles |
| 🎵 Bard | 2x gold winnings on 3+ win streaks |

## 🚀 Play

Open `index.html` in any modern browser — no server required! All data is saved to localStorage.

## 🛠️ Tech Stack

- Pure HTML/CSS/JavaScript
- No frameworks or dependencies
- localStorage for persistence
- Web Audio API for sound effects
